Guia de Táticas

📚 Guia do Sistema de Táticas e Templates

Este guia explica como o sistema de Facções e Táticas interage com a ficha (Template - Unit.md), e como você mesmo pode adicionar, remover ou modificar táticas nas páginas de facções de forma simples e rápida, e como elas atualizarão a ficha automaticamente.

1. Como a Ficha lê as Táticas?

O Template - Unit.md contém um bloco de Javascript do Dataview que varre automaticamente a pasta Wargame/03 Facções toda vez que você abre a nota da unidade.

Isso significa que o filtro da ficha se ajusta em tempo real:

  • Se você criar um novo arquivo dentro da pasta 03 Facções, essa facção aparecerá no primeiro seletor automaticamente.
  • Se você adicionar ou remover uma tática no código YAML de uma facção existente, o segundo seletor será preenchido com as táticas exatas daquele arquivo.

2. Como adicionar Novas Táticas?

As táticas são controladas exclusivamente pelo código Frontmatter (YAML) no topo do arquivo da sua Facção (por exemplo: c:\Noosphera\Wargame\03 Facções\Casacas.md).

Para adicionar uma nova tática, você precisa apenas abrir o arquivo da facção e adicionar o bloco de código dentro da propriedade taticas:.

Estrutura Base

---
noosphera: Ryke
taticas:
  - nome: Nome da Sua Tática
    efeitos:
      # coloque os efeitos suportados aqui!
---

O que acontece por baixo dos panos:

  1. O campo noosphera: Ryke é o que dita a que dimensão aquela facção pertence. A ficha pega esse valor e compara com a da Unidade. Se forem diferentes, ela soma automaticamente +20 no custo de pontos da ficha.
  2. A lista de taticas: é um array (marcado pelo hífen -). Você pode colocar infinitas táticas descendo a lista com novos hifens.

3. Lógica de Efeitos Suportados

Para ser "facilmente editável", o motor de JavaScript da ficha procura por chaves específicas dentro de efeitos:. Se você escrever exatamente as chaves abaixo, o sistema matemático e visual da ficha vai atualizar a caixa de forma automática (mudando para amarelo-dourado e calculando matemática).

Dica: Eu acabei de atualizar o sistema para suportar também Movimento, Decoerência e AP!

Aqui estão todos os efeitos suportados atualmente na ficha da Unidade:

Atributos Core (Adição ou Subtração)

Estes comandos somam o número ao valor base da ficha. Se você colocar números negativos, eles subtraem.

  • movimento: 1 -> (+1 de Movimento)
  • decoerencia: -2 -> (-2 de Decoerência)
  • ap: 1 -> (+1 Ponto de Ação / AP)
  • vida: 2 -> (+2 Pontos de Vida)
  • defesa_melee: -1 -> (Reduz armadura corpo-a-corpo em -1)
  • defesa_ranged: -1 -> (Reduz armadura de tiro em -1)
  • defesa_special: 1 -> (Soma armadura especial em +1)

Tags e Habilidades

Estes comandos inserem visualmente os blocos dourados com a marcação (TÁTICA) no final do texto.

  • caracteristica: "NOME" -> Renderiza uma tag na lista de características (junto de Elite/Commander). Ideal para conceder Stealth, Aura, etc.
  • ativa: "NOME DA AÇÃO" (ou lista YAML) -> Usa o Glossário - Ações (maps.active no export). Aparece na seção Ações (tática) da ficha.
  • passiva: "NOME DA PASSIVA" (ou lista separada por vírgula / array YAML) -> Usa o Glossário - Passivas (maps.passive). Aparece na seção Passivas (tática) abaixo das tags do modelo.

Loadout (peso máximo do equipamento)

  • loadout_max: 1 -> Soma esse valor ao loadout_max base da unidade só enquanto a tática estiver selecionada. O rodapé PESO (arma / máximo) recalcula automaticamente no HTML exportado (motor em export-fixes.md, initUnitDashboard → updateTatica + updateWeapon).

4. Exemplo Completo para Copiar e Colar

Se você quiser criar uma facção com várias opções, o arquivo .md dessa facção deve se parecer com isso:

---
noosphera: Ryke
taticas:
  - nome: Berserkers Químicos
    efeitos:
      vida: 2
      defesa_melee: -1
      defesa_ranged: -1
      ap: 1
      ativa: Investida Feroz
      
  - nome: Tropa Fantasma
    efeitos:
      movimento: 2
      caracteristica: Stealth
      
  - nome: Protocolo Parede de Escudos
    efeitos:
      movimento: -2
      defesa_melee: 1
      defesa_ranged: 1
---

Apenas editando isso no arquivo da facção, o seu Template - Unit.md fará todo o resto de ler, calcular, destacar em amarelo as mudanças, e aplicar as lógicas de pontos bônus por você!

5. Arquitetura do Sistema — Onde fica o quê

Esta é a parte mais importante para quem vai criar muitas fichas usando o Template - Unit.md como base.

Important

Você nunca precisa editar o Template - Unit.md para adicionar ou modificar táticas. Toda a lógica de interpretação já está lá — você só precisa editar os arquivos de facção.

Mapa de responsabilidades

O que é Onde fica Quem edita
Nomes das táticas YAML da página de facção Você
Efeitos das táticas YAML da página de facção Você
Texto/lore da tática Corpo da página de facção Você
Aplicação dos efeitos na ficha (export HTML) export-fixes.md → initUnitDashboard Manutenção rara (patch global)
Dataview na Obsidian Bloco JS da ficha / Squad Builder Copiar do template ao criar modelo
Lógica de custo por noosphera (+20 / incompatível) Mesmo motor acima —

Como o Template descobre as táticas

O Template - Unit.md (e fichas de modelo que copiam o mesmo DataviewJS) varre Wargame/03 Facções/ e monta name, noosphera e taticas. A fonte de verdade mecânica é o array YAML taticas: com efeitos em cada entrada.

Se uma página de facção ainda não tiver taticas: preenchido, o script usa fallback: lê tactic1_name … tactic12_name do frontmatter (banners antigos) e cria entradas com efeitos: {} até você migrar para YAML completo.

No site estático (export HTML), o mesmo comportamento de seletores, comparação de noosphera, modificadores numéricos (incluindo 0), passiva / ativa, loadout_max e atualização do bloco de arma fica centralizado no patch global **export-fixes.md** (window.initUnitDashboard).

Isso significa que o template não tem táticas fixas no código. Consequentemente:

  • Criar um novo arquivo em Wargame/03 Facções/ → a facção aparece no seletor automaticamente
  • Adicionar uma nova entrada em taticas: num arquivo de facção → a tática aparece no dropdown automaticamente
  • Remover uma entrada → some do dropdown automaticamente

Fluxo completo ao selecionar uma tática

Usuário seleciona Facção → Template lê o YAML daquele arquivo de facção
Usuário seleciona Tática  → Template lê os efeitos do bloco `efeitos:` daquela tática
                          → Compara a noosphera da facção com a da unidade
                          → Se mesma noosphera, mesma facção: custo normal
                          → Se mesma noosphera, facção diferente: +20 PTS (badge amarelo)
                          → Se noosphera diferente: XXXXX (badge vermelho, bloqueado)
                          → Aplica os efeitos nos atributos (dourado = modificado por tática)
                          → Exibe bloco resumo: "⚡ TÁTICA: X · Facção Y — +1 Vida · Ganha Stealth"

6. Criando Fichas de Modelos com o Template

Para criar a ficha de um novo modelo usando o Template - Unit.md como base:

  1. Crie um novo arquivo .md na pasta do modelo (ex: Wargame/02 Models/NomeDaFaccao/NomeDoModel.md)
  2. Copie o frontmatter do Template - Unit.md e ajuste os valores:
 ---
 tipo: Model
 pontos: "80"
 faccao:
   - Casacas
 noosphera: Ryke
 keywords:
   - Soldier
 caracteristicas:
   - Commander 6'
 habilidades_ativas:
   - Sobrecarga
 habilidades_passivas:
   - Protocolo de Esquiva
 habilidades_padrao:
   - Mover
   - Combater
 movimento: "4"
 vida: "3"
 armadura_melee: "2"
 armadura_ranged: "2"
 armadura_special: "1"
 loadout_max: "3"
 decoerencia: "5"
 ap: "3"
 utility1: "[[Nome da Arma]]"
 model_image: "[[NomeDoModel.png]]"
 ---
  1. Cole o bloco DataviewJS do Template - Unit.md (o bloco entre os três crases) — ele funciona identicamente em qualquer arquivo que tenha o frontmatter correto.
  2. As táticas aparecerão automaticamente sem nenhuma configuração adicional.
Tip

Habilidades passivas e ativas são buscadas automaticamente nos arquivos de Glossário. Se você usar um nome que não existe lá, aparecerá "Descrição não encontrada no glossário" — basta adicionar a habilidade no glossário correspondente.
